# Milestone 2: Everyday Security and Phishing Checks

## 1. Objective
The objective of this task is to identify warning signs in suspicious messages and understand practical personal cybersecurity measures.

## 2. Phishing Message Analysis

### Message 1: Urgent Payment Request
**Warning Sign:** Urgent payment request with mismatched bank account details.

**Analysis:** Fraudsters may create urgency and provide incorrect bank details to redirect payments.

**Uncertainty:** The message cannot be confirmed as phishing based on appearance alone. Verify payment details through a known official contact.

### Message 2: College Password Request
**Warning Sign:** A message requests a password through a suspicious login link.

**Analysis:** Password requests through unfamiliar links may indicate phishing attempts.

**Uncertainty:** The sender's identity cannot be confirmed from the message alone. Verify through the official college website or IT department.

### Message 3: Unexpected Invoice Attachment
**Warning Sign:** An unexpected invoice attachment.

**Analysis:** Unexpected attachments may contain malware or fraudulent payment requests.

**Uncertainty:** Not every unexpected attachment is malicious. Verify the sender through a trusted channel before opening it.

## 3. Personal Security Checklist

1. **Unique Passwords:** Use strong and unique passwords for every account.
2. **MFA:** Enable Multi-Factor Authentication wherever available.
3. **Updates:** Keep operating systems, browsers and applications updated.
4. **Link Checks:** Verify website addresses before clicking links or entering personal information.
5. **Account Recovery:** Keep recovery email addresses and phone numbers updated.
